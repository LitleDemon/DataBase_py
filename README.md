# 📊 MyDB — Портативная база данных

Простое и удобное десктопное приложение для создания собственных баз данных. 
Программа позволяет на лету создавать таблицы, задавать произвольное количество полей, указывать их типы и вести учет любых записей. 

Приложение работает полностью автономно, не требует установки серверов, настройки сети или дополнительного программного обеспечения.

---

## 👨‍💻 Для пользователя (Как начать работу)

### 1. Установка и запуск
1. Перейдите в раздел **Releases** (Релизы) справа на этой странице.
2. Скачайте последнюю версию файла **`DataBase.exe`**.
3. Переместите файл в удобную для вас папку (например, на Рабочий стол).
4. Запустите двойным кликом.

> **⚠️ Важно:** При первом запуске Windows может показать синее окно «Windows защитила ваш компьютер» (SmartScreen). Это нормальная реакция на новые программы без платной цифровой подписи. Нажмите **«Подробнее»** -> **«Выполнить в любом случае»**.

### 2. Где хранятся мои данные?
Все ваши таблицы и записи надежно сохраняются в файле базы данных. Чтобы вы случайно не потеряли данные при перемещении `.exe` файла, база хранится в системной папке:
`C:\Users\Ваше_Имя\AppData\Roaming\DataBase\data.db`

### 3. Как сделать резервную копию?
В левой панели программы есть оранжевая кнопка **«Резервная копия»**. 
Нажмите её, выберите удобное место (например, флешку или рабочий стол) и сохраните файл `.db`. 
*Чтобы восстановить данные или перенести их на другой компьютер, просто скопируйте этот файл обратно в папку `AppData\Roaming\DataBase` и замените старый.*

## 🛠 Для разработчика (Сборка из исходников)

Если вы хотите внести изменения в код или собрать `.exe` самостоятельно, выполните следующие шаги.

### Требования
*   **Python** версии 3.10 или выше.
*   Установленный пакетный менеджер `pip`.

### Установка зависимостей

Клонируйте репозиторий и установите необходимые библиотеки (в проекте используется `CustomTkinter` для современного интерфейса и `PyInstaller` для сборки):

```bash
pip install customtkinter pyinstaller
```

*(Также можно использовать `pip install -r requirements.txt`, если файл добавлен в репозиторий).*

### Запуск в режиме разработки

Чтобы протестировать программу без сборки, запустите:

```bash
python main.py
```

### Сборка в один EXE-файл

Для создания портативного исполняемого файла выполните в терминале команду:

```bash
python -m PyInstaller --onedir --windowed --name "DataBase" main.py
```

После завершения сборки готовый файл `DataBase.exe` появится в папке `DataBase` с папкой `_internal` в папке `dist`.

### 📁 Структура проекта

*   **`main.py`** — основной исходный код приложения (интерфейс, логика БД).
